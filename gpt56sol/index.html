01 / The connection

Both systems can care less about how much is present than about what just changed.

This page gives a stylized nose and bacterium the same adaptive circuit: current input is compared with a slow memory of recent input. A jump matters immediately. If it persists, memory catches up and the response returns toward zero. Change it again and attention returns.

This is a mathematical analogy. It does not claim that olfactory neurons and bacterial chemotaxis use identical biology. It shows how the same adaptive computation can make both systems sensitive to novelty across very different scales.

03 / Under the surface

Open the mechanism ＋

Fast comparison, slow memory

The model stores a moving memory of concentration. Its output is the logarithm of current concentration divided by that memory. Equal fold changes therefore draw equal response traces, even when their absolute levels differ.

The named science

Bacterial chemotaxis is a classic example of sensory adaptation; work by Naama Barkai and Stanislas Leibler showed how its network can recover a stable response despite changing component details. Olfactory systems also reduce their response during sustained stimulation through adaptive feedback.

What would change the conclusion

The analogy would fail in this model if a held fourfold signal kept more than the allowed fraction of its first flare, if equal fold changes drew different traces, or if adaptation prevented a fresh change from breaking through. The checks below attack all three conditions.

Where the analogy stops

This deterministic circuit has no receptor noise, spatial swimming, airflow, neural population, or saturation. It demonstrates a computation, not a full organism. A mismatch with biology would indict this miniature model before either field’s evidence.
