02 · What is shared

When each event triggers fewer than one successor on average, cascades tend to end. Above one, most still end, but a dangerous tail of self-sustaining chains appears.

This is a mathematical analogy, not evidence that inboxes and faults are physically alike. The page gives both worlds one Galton–Watson branching tree. Earthquake forecasting uses richer descendants of this idea, including Yosihiko Ogata’s ETAS model; the email side is deliberately stylised.

What would change the claim? If the 200 fixed seeds below R 1 produced large cascades as often as those above it, or if the high-R average failed to separate sharply, the threshold story would not survive this model.

04 · Open the mechanismWhy one matters

The shared rule

Each event draws a random number of children from a Poisson distribution whose mean is R. Children repeat the same rule for at most 12 generations. The expected population shrinks when R is below one and can grow when it is above one.

The fault-world caveat

Real aftershock models account for time, location, and magnitude. ETAS is a self-exciting point process, not this small classroom tree. This page isolates its branching intuition and does not forecast earthquakes.

The inbox-world caveat

No email dataset was fitted. A reply is simply assigned the same offspring rule to make the threshold tactile. The analogy predicts what this model does; it does not claim a measured reproduction number for office mail.

The finite edge

The simulation stops at 12 generations or 700 events so the browser stays responsive. That cap compresses the largest supercritical runs, meaning 74.145 is a bounded demonstration average, not the unrestricted process mean.
