Thesis

The same local rule makes both systems tip.

A tiny disruption only grows when a threshold is crossed. In a power network, one overloaded substation trips the neighbors that are already near their limit. In a social network, one nervous person only triggers panic when enough friends are already panicking. The rule is the same: each node flips when enough neighbors have already flipped.

Deep model

What the mechanism is

This is a threshold model, and the specific family is bootstrap percolation. A node starts silent, then becomes active only after enough neighbors are already active. That creates a tipping point: below the critical level, the cascade dies out; above it, the system jumps into a self-amplifying wave.

The label changes with the domain, but the math does not. Power grids call it overload propagation; rumor networks call it contagion. In both settings, weakly connected regions stay stable, but once the local threshold is reached, the system becomes a chain reaction.

The shipped run measured this directly: at density 0.05 the model produced 6 active cells, while at density 0.18 it reached 144. A threshold of 2 produced 144 active cells, but a stricter threshold of 4 produced only 30. This is the same local rule, just described in different language.
